# Сайт с погодой
Небольшой сайт написанный на HTML + CSS + JS в рамках университетской лабораторной работы.

Этот сайт обучил меня основам JS, HTML и CSS.

Позволяет просматривать погоду в текущей геопозции, а также добавлять в список избранного города для мониторинга погоды в них.

Погода берётся из OpenWeatherMap
